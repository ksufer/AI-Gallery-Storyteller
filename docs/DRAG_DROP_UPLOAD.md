# 拖拽和粘贴上传功能

## 📅 实施日期
2026-01-30

## 🎯 功能说明

为图库应用添加了更便捷的图片上传方式，用户现在可以通过三种方式上传图片：

### 1. 🖱️ 拖拽上传（Drag & Drop）
- 从文件管理器拖拽图片到页面任意位置
- 拖拽时显示半透明蓝色提示层
- 支持同时拖拽多张图片
- 自动过滤非图片文件

### 2. 📋 粘贴上传（Paste）
- 复制图片后按 `Ctrl+V`（或 `Cmd+V`）粘贴
- 支持从截图工具、浏览器等复制的图片
- 可以连续粘贴多张图片

### 3. 🗂️ 传统按钮上传
- 批量上传按钮：选择多个文件
- 上传文件夹按钮：选择整个文件夹

## 🎨 用户体验

### 拖拽上传流程
1. 用户从文件管理器选择图片
2. 拖拽到浏览器窗口
3. 页面显示蓝色提示层："拖放图片到这里"
4. 释放鼠标完成上传
5. 显示上传成功提示
6. 自动刷新图库

### 粘贴上传流程
1. 用户复制图片（截图、网页图片等）
2. 在页面任意位置按 `Ctrl+V`
3. 自动开始上传
4. 显示上传成功提示
5. 自动刷新图库

### 文件过滤
```typescript
// 拖拽上传
const files = Array.from(e.dataTransfer.files).filter((file: File) => 
  file.type.startsWith('image/')
);

// 粘贴上传
if (items[i].type.startsWith('image/')) {
  const file = items[i].getAsFile();
```

### 性能优化
- 使用 `React.useCallback` 包装 `uploadFiles` 避免重复创建
- 拖拽事件处理中使用 `preventDefault()` 和 `stopPropagation()`
- 粘贴监听器在组件卸载时自动清理

### 状态管理
- `isDragging` - 控制拖拽提示层的显示/隐藏
- `isUploading` - 统一的上传中状态
- `uploadStatus` - 上传结果提示（成功/失败）

## 📝 注意事项

1. **粘贴功能限制**：
   - 不支持粘贴文件路径（只支持图片数据）
   - 某些应用复制的图片可能无法粘贴（取决于剪贴板格式）

2. **拖拽功能限制**：
   - 拖拽时浏览器可能会尝试打开图片（已通过 `preventDefault()` 阻止）
   - 部分安全限制可能影响某些来源的文件

3. **性能考虑**：
   - 上传大量图片时会有延迟
   - 建议单次上传不超过 100 张图片
