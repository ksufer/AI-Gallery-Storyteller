## Gemini API 相关问题

### ❌ 错误：`PROHIBITED_CONTENT`

**症状**：生成故事时返回 `[提示词拦截] 原因: PROHIBITED_CONTENT`

**原因**：
1. 提示词包含敏感内容（年龄相关、成人内容等）
2. 图片本身触发了 Gemini 的安全过滤器
3. 图片 + 提示词的组合超出了 API 的容忍度

**解决方案**：

1. **检查过滤日志**
   ```
   打开浏览器控制台 (F12)
   查看 "=== Gemini Request Debug ===" 输出
   检查 "Filtered Prompts" 是否正确过滤了敏感词
   ```

2. **添加更多禁词**
   - 打开设置界面（点击右上角齿轮图标）
   - 在"禁词替换表"中添加被拦截的词汇
   - 例如：`"少女" → "美女"`，`"学生" → "年轻女子"`

3. **检查降级策略**
   - 如果看到 `（提示词未通过）` 后缀，说明系统已自动使用降级策略
   - 此时故事仅基于图片生成，不依赖提示词
   - 如果降级也失败，说明图片本身被拦截

4. **手动编辑故事**
   - 如果 AI 生成失败，可以手动编写故事
   - 在详情页的故事文本框中直接输入
   - 焦点离开时自动保存

### ❌ 错误：`未设置 API 密钥`

**症状**：点击"AI 生成故事"时弹出错误提示

**原因**：环境变量中没有配置 Gemini API Key

**解决方案**：

1. 检查 `.env.local` 文件是否存在
   ```bash
   # Windows (PowerShell)
   Test-Path .env.local
   
   # CMD
   dir .env.local
   ```

2. 如果不存在，创建文件
   ```bash
   copy .env.local.example .env.local
   ```

3. 编辑 `.env.local`，填入真实的 API Key
   ```env
   GEMINI_API_KEY=your_actual_api_key_here
   ```

4. 重启开发服务器
   ```bash
   # 按 Ctrl+C 停止服务器
   npm run dev
   ```

### ❌ 错误：`SAFETY_BLOCK`

**症状**：生成被标记为敏感内容

**原因**：Gemini 的安全评级系统判定内容为 HIGH 或 MEDIUM 风险

**解决方案**：

1. **检查安全评级**
   - 控制台会显示：`[安全拦截] 内容被标记为敏感: CATEGORY (PROBABILITY)`
   - 查看具体的分类和概率

2. **优化提示词**
   - 移除可能触发安全过滤的词汇
   - 在禁词表中添加替换规则

3. **调整系统指令**（高级）
   - 修改 `services/geminiService.ts` 中的 `SYSTEM_INSTRUCTION`
   - 注意：不当的修改可能导致生成质量下降

---

### ⚠️ 错误：`API quota exceeded`

**症状**：达到 API 调用配额限制

**原因**：
- 免费版 Gemini API 有每日/每分钟调用限制
- 短时间内生成了过多故事

**解决方案**：

1. **等待配额重置**
   - 免费版：每分钟 15 次请求
   - 查看 [Google AI Studio](https://aistudio.google.com/app/apikey) 的配额使用情况

2. **升级 API 计划**
   - 升级到付费版本以获得更高配额

3. **优化使用**
   - 不要连续快速点击"生成故事"按钮
   - 批量生成故事时添加延迟

## 图片上传问题

### ❌ 错误：上传失败 / 无响应

**症状**：点击上传按钮后没有反应，或显示"上传失败"

**原因**：
1. 文件格式不支持
2. 文件大小超过限制（500MB）
3. 文件损坏或无法读取
4. 网络连接问题

**解决方案**：

1. **检查文件格式**
   - 支持的格式：PNG (.png), JPEG (.jpg, .jpeg), WebP (.webp)
   - 不支持：GIF, BMP, TIFF 等格式

2. **检查文件大小**
   ```bash
   # Windows (PowerShell)
   (Get-Item image.png).length / 1MB
   
   # CMD (使用文件属性)
   # 右键 -> 属性 -> 查看大小
   ```
   - 如果超过 500MB，压缩或裁剪图片后再上传

3. **检查控制台错误**
   - 打开浏览器控制台 (F12)
   - 查看 Network 标签中的 `/api/upload` 请求
   - 查看响应内容中的具体错误信息

4. **检查服务器日志**
   - 在运行 `npm run dev` 的终端窗口查看错误输出

---

### ❌ 错误：元数据解析失败

**症状**：图片上传成功，但显示 "Unknown" 类型，没有元数据

**原因**：
1. 图片不是从 ComfyUI 或 SD WebUI 生成的
2. PNG 元数据已被删除（如经过压缩工具处理）
3. 图片格式损坏

**解决方案**：

1. **检查图片来源**
   - 确保图片是从 ComfyUI 或 SD WebUI 直接导出的 PNG 格式
   - 不要使用"另存为"或截图工具保存

2. **使用 Python 脚本验证**
   ```bash
   python analyze_images.py
   ```
   - 查看是否能正确解析元数据

3. **手动添加标签**
   - 即使元数据缺失，仍可以手动添加用户标签

---

### ❌ 错误：拖拽上传无效

**症状**：拖拽图片到页面后没有反应

**原因**：
1. 拖拽的不是图片文件
2. 浏览器安全限制
3. JavaScript 错误

**解决方案**：

1. **检查文件类型**
   - 确保拖拽的是图片文件，不是快捷方式或文件夹

2. **检查浏览器兼容性**
   - 推荐使用 Chrome、Edge 或 Firefox 最新版本
   - Safari 可能存在兼容性问题

3. **检查控制台错误**
   - 打开 F12 查看是否有 JavaScript 错误

## 数据库问题

### ❌ 错误：`database is locked`

**症状**：操作图片时出现数据库锁定错误

**原因**：
1. 多个进程同时访问数据库
2. 数据库文件被其他程序占用
3. WAL 模式文件未正确清理

**解决方案**：

1. **关闭所有服务器进程**
   ```bash
   # 按 Ctrl+C 停止当前服务器
   # 检查是否有其他 Node.js 进程
   
   # Windows (PowerShell)
   Get-Process node
   
   # CMD
   tasklist | findstr node.exe
   ```

2. **删除 WAL 文件**
   ```bash
   # 停止服务器后删除
   del db\images.db-wal
   del db\images.db-shm
   ```

3. **重启服务器**
   ```bash
   npm run dev
   ```

---

### ❌ 错误：图片显示不同步

**症状**：删除或添加图片后，列表没有更新

**原因**：
1. 前端缓存未刷新
2. 数据库同步延迟

**解决方案**：

1. **刷新页面**
   - 按 `F5` 或 `Ctrl+R` 刷新浏览器

2. **清除浏览器缓存**
   - 按 `Ctrl+Shift+Delete` 打开清除缓存界面
   - 选择"缓存的图片和文件"
   - 点击"清除数据"

3. **检查自动同步**
   - 服务器每 60 秒自动扫描 `uploads` 目录
   - 等待 1 分钟后刷新页面

## 前端显示问题

### ❌ 错误：瀑布流布局混乱

**症状**：图片卡片重叠或间距异常

**原因**：
1. 虚拟滚动组件状态异常
2. CSS 样式冲突
3. 窗口大小调整时未正确重新计算

**解决方案**：

1. **刷新页面**
   - 按 `F5` 刷新

2. **调整浏览器窗口**
   - 拖动窗口边缘改变大小
   - 虚拟滚动会自动重新计算布局

3. **清除浏览器缓存**
   - CSS 样式可能被缓存

---

### ❌ 错误：图片加载缓慢

**症状**：滚动时图片显示延迟

**原因**：
1. 网络速度慢
2. 图片文件过大
3. 浏览器性能限制

**解决方案**：

1. **检查图片大小**
   - 大图片会显著影响加载速度
   - 建议单张图片不超过 10MB

2. **启用懒加载**
   - 项目已默认启用 `loading="lazy"`
   - 确保使用最新版本的浏览器

3. **减少同时打开的标签页**
   - 浏览器内存不足会影响性能

---

### ❌ 错误：无限滚动不工作

**症状**：滚动到底部后不再加载更多图片

**原因**：
1. 已经加载了所有图片
2. API 错误
3. 前端状态异常

**解决方案**：

1. **检查是否还有更多图片**
   - 查看页面标题栏的图片总数
   - 如果已显示全部，则正常

2. **检查控制台**
   - 打开 F12 查看是否有 API 错误
   - 查看 Network 标签中的 `/api/images` 请求

3. **刷新页面**
   - 重置加载状态

## 性能问题

### ⚠️ 问题：页面卡顿

**症状**：滚动或交互时页面反应缓慢

**原因**：
1. 图片数量过多
2. 浏览器内存不足
3. 其他应用程序占用资源

**解决方案**：

1. **使用筛选功能**
   - 按日期或标签筛选，减少显示的图片数量

2. **关闭不必要的标签页**
   - 每个标签页都占用内存

3. **清理浏览器缓存**
   - 释放内存空间

4. **增加系统内存**
   - 如果经常处理大量图片，考虑升级硬件

---

### ⚠️ 问题：启动速度慢

**症状**：运行 `npm run dev` 后等待时间长

**原因**：
1. 首次启动需要同步数据库
2. `uploads` 目录包含大量图片
3. Node.js 模块加载缓慢

**解决方案**：

1. **等待初始化完成**
   - 首次启动可能需要 10-30 秒
   - 控制台会显示 "Initialization complete."

2. **减少 uploads 目录中的图片**
   - 移动旧图片到备份目录
   - 只保留常用的图片

3. **使用 SSD 硬盘**
   - SSD 的读写速度远快于 HDD

## 配置文件问题

### ❌ 错误：设置保存失败

**症状**：修改禁词表或屏蔽标签后保存失败

**原因**：
1. 文件写入权限不足
2. JSON 格式错误
3. 配置目录不存在

**解决方案**：

1. **检查文件权限**
   ```bash
   # Windows (PowerShell)
   Get-Acl config\forbidden-words.json
   ```
   - 确保当前用户有写入权限

2. **验证 JSON 格式**
   - 使用 [JSONLint](https://jsonlint.com/) 验证 JSON 格式
   - 检查是否有多余的逗号或引号

3. **手动创建配置目录**
   ```bash
   # Windows (CMD)
   mkdir config
   ```

---

### ❌ 错误：配置未生效

**症状**：修改配置文件后没有效果

**原因**：
1. 没有刷新页面
2. 缓存未清除
3. 配置文件路径错误

**解决方案**：

1. **刷新页面**
   - 按 `Ctrl+Shift+R` 强制刷新（清除缓存）

2. **重启服务器**
   ```bash
   # 按 Ctrl+C 停止
   npm run dev
   ```

3. **检查文件名**
   - 确保文件名是 `forbidden-words.json`，不是 `.txt` 或其他后缀
   - Windows 默认隐藏扩展名，注意检查

## 调试技巧

### 查看详细日志

**后端日志**：
- 在运行 `npm run dev` 的终端窗口查看
- 所有 API 请求和错误都会输出

**前端日志**：
- 按 `F12` 打开浏览器控制台
- 查看 Console 标签
- 查看 Network 标签中的 API 请求

**Gemini API 调试**：
```
=== Gemini Request Debug ===
Model: gemini-3-flash-preview
--- System Instruction ---
[系统指令内容]
--------------------------
Original Prompts: [原始提示词]
Filtered Prompts: [过滤后的提示词]
...
============================
```
