# 配置文件说明

本目录包含应用的配置文件。

## forbidden-words.json

禁词替换表配置文件，用于在生成故事前自动替换提示词中的敏感词汇。

### 文件格式

```json
{
  "需要替换的词": "替换后的词",
  "另一个词": "另一个替换"
}
```

### 使用方法

1. 如果 `forbidden-words.json` 不存在，将 `forbidden-words.example.json` 复制为 `forbidden-words.json`
2. 编辑 `forbidden-words.json`，添加您需要的词汇映射
3. 保存文件后重启服务器，配置会在应用启动时自动加载

### 示例

```json
{
  "裸露": "展现",
  "露出": "呈现",
  "乳沟": "轮廓",
  "侧乳": "侧影",
  "丁字裤": "内衣",
  "蕾丝": "精致",
  "掀起裙边": "裙摆飘动"
}
```

### 注意事项

- 替换是**不区分大小写**的
- 使用**全局替换**，会替换所有匹配项
- 按顺序执行替换（JSON 对象的顺序可能因实现而异）
- 如果文件加载失败，应用会使用空的禁词表（不影响正常功能）

### 调试

应用启动时，控制台会显示：
```
✓ 已加载禁词表: X 个词汇
```

如果加载失败，会显示警告：
```
⚠ 无法加载禁词表配置文件，将使用空的禁词表
```

### 动态更新

**推荐方式**：通过设置界面管理（无需重启）
1. 点击应用右上角的"设置"按钮
2. 在"禁词替换表"标签页中编辑配置
3. 点击"保存设置"
4. 刷新页面即可生效

**手动编辑**：如果直接编辑 JSON 文件
- 修改后刷新页面即可生效（无需重启服务器）

## blocked-tags.json

标签屏蔽列表配置文件，用于在自动提取标签时过滤掉无意义的标签。

### 文件格式

```json
[
  "标签1",
  "标签2",
  "标签3"
]
```

### 使用方法

1. 如果 `blocked-tags.json` 不存在，将 `blocked-tags.example.json` 复制为 `blocked-tags.json`
2. 编辑 `blocked-tags.json`，添加您需要屏蔽的标签
3. 保存文件后重启服务器，配置会在应用启动时自动加载

### 示例

```json
[
  "masterpiece",
  "best quality",
  "high quality",
  "extremely detailed",
  "8k",
  "4k",
  "bokeh",
  "depth of field",
  "sharp focus",
  "cinematic lighting",
  "wide shot",
  "close-up",
  "looking at viewer"
]
```

### 用途

- 屏蔽无意义的图像质量词（masterpiece, best quality, high quality等）
- 屏蔽镜头相关词汇（wide shot, close-up, from above等）
- 屏蔽光照相关词汇（cinematic lighting, dramatic lighting等）
- 屏蔽画质相关词汇（8k, 4k, absurdres等）
- 屏蔽技术性描述词（detailed face, perfect anatomy等）

### 注意事项

- 匹配是**不区分大小写**的
- 支持**关键词/正则匹配**：只要标签包含列表中的任意词（或匹配正则表达式），该标签就会被屏蔽
  - 例如：设置 "quality" 会屏蔽 "best quality", "high quality", "low quality" 等所有包含 "quality" 的标签
- 仅影响**自动提取的标签**，不影响用户手动添加的标签
- 用户手动添加的标签会单独显示在"用户标签"区域
- 如果文件加载失败，应用不会屏蔽任何标签（所有标签都会显示）

### 动态更新

**推荐方式**：通过设置界面管理（无需重启）
1. 点击应用右上角的"设置"按钮
2. 在"标签屏蔽列表"标签页中编辑配置
3. 点击"保存设置"，配置会立即生效
4. 仅对新导入的图片有效

**手动编辑**：如果直接编辑 JSON 文件
- 修改后保存即可立即生效（无需重启服务器）
- API 会自动重新加载配置

### 调试

应用启动时，控制台会显示：
```
✓ Loaded X blocked tags
```

如果加载失败，会显示警告：
```
⚠ Could not load blocked-tags.json, using empty blocklist
```

## system-prompt.json

系统提示词配置文件，用于定义 AI 生成故事时的角色、风格和规则。

### 文件格式

```json
{
  "content": "你的系统提示词内容..."
}
```

### 使用方法

1. 如果 `system-prompt.json` 不存在，将 `system-prompt.example.json` 复制为 `system-prompt.json`
2. 编辑 `system-prompt.json`，自定义 AI 的角色、风格和输出格式
3. 保存文件后即可生效（无需重启服务器）

### 示例

```json
{
  "content": "# Role\n你是一位擅长视觉美学与叙事艺术的\"沉浸式微小说家\"。\n\n# Task\n根据【视觉画面】和【生成提示词】，创作 100-150 字的微型故事或场景独白。\n\n# Guidelines\n1. **沉浸式写作**：调动感官描写（光影、温度、声音、触感）。Show, don't tell。\n2. **去技术化**：禁止出现技术术语。\n3. **语言风格**：高级、细腻、有质感。"
}
```

### 用途

- 定义 AI 的角色定位（编剧、小说家、诗人等）
- 设置故事风格（冰山叙事、浪漫主义、现实主义等）
- 规定输出格式（字数、结构、markdown 格式等）
- 添加写作规则和禁忌事项

### 注意事项

- 提示词内容使用 `\n` 表示换行（JSON 格式要求）
- 提示词会直接传递给 AI，影响所有故事生成
- 建议使用 Markdown 格式编写，结构清晰易读
- 过长的提示词可能影响 API 响应速度和成本

### 动态更新

**推荐方式**：通过设置界面管理（无需重启）
1. 点击应用右上角的"设置"按钮
2. 在"系统提示词"标签页中编辑配置
3. 点击"保存设置"，配置会立即重新加载
4. 下次生成故事时将使用新的提示词

**手动编辑**：如果直接编辑 JSON 文件
- 修改后刷新页面即可生效（无需重启服务器）
- 系统会自动重新加载配置

### 调试

应用启动时，控制台会显示：
```
✓ 已加载系统提示词 (X 字符)
```

如果加载失败，会显示警告并使用默认提示词：
```
⚠ 无法加载系统提示词配置文件，将使用默认提示词
```
